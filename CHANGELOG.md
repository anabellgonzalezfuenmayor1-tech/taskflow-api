## [0.1.0] - 2026-10-21

### Added
- Proyecto base con Laravel 13, PHP 8.3 y MySQL 8.
- Endpoint de estado del servicio `GET /api/v1/health`.
- Respuestas de error en JSON para las rutas `/api`.
- Prefijo configurable de tablas mediante `DB_PREFIX`.
- Pruebas automatizadas con Pest y flujo de integración continua en GitHub Actions.
- Documentación de la API con Scramble en `/docs/api`.
- `README.md` y `LICENSE.md`.
